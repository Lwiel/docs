# Configuration: Tombstone Options

<Admonition type="info" title="Tombstones.CleanupIntervalInMin" id="tombstones-cleanupintervalinmin" href="#tombstones-cleanupintervalinmin">

Time (in minutes) between tombstone cleanups.

- **Type**: `TimeUnit.Minutes`
- **Default**: `5`
- **Scope**: Server-wide or per database
</Admonition>

<Admonition type="info" title="Tombstones.RetentionTimeWithReplicationHubInHrs" id="tombstones-retentiontimewithreplicationhubinhrs" href="#tombstones-retentiontimewithreplicationhubinhrs">

Time (in hours) to save tombsones from deletion if this server is defined 
as a replication hub.  

- **Type**: `TimeUnit.Hours`
- **Default**: `336` (14 days)
- **Scope**: Server-wide or per database
</Admonition>

<Admonition type="info" title="Tombstones.CleanupIntervalWithReplicationHubInMin" id="tombstones-cleanupintervalwithreplicationhubinmin" href="#tombstones-cleanupintervalwithreplicationhubinmin">

Time (in minutes) between tombstone cleanups if this server is defined as 
a replication hub.  

- **Type**: `TimeUnit.Minutes`
- **Default**: `1440` (1 day)
- **Scope**: Server-wide or per database
</Admonition>
