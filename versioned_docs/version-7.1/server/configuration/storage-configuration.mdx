# Configuration: Storage Options

The following configuration options allow you configure [the storage engine](../../server/storage/storage-engine).

<Admonition type="info" title="Storage.TempPath" id="storage-temppath" href="#storage-temppath">

* Use this configuration option to customize the path for the temporary files of the following [directories](../../server/storage/directory-structure):
  * `System`
  * `Configuration` 
  * `Databases/{database_name}`

* By default, the temporary files are created under the `Temp` folder in those directories.

* When the `Storage.TempPath` is configured:  

  * The System temporary files will be written to `"<Storage.TempPath>/System"`.  
  * The Databases temporary files will be written to `"<Storage.TempPath>/Databases/{database-name}"`.  
  * The Configuration temporary files will be written to `"<Storage.TempPath>/Databases/{database-name}/Configuration"`.  

* To specify a different path for the indexes temporary files go to [Indexing.TempPath](../../server/configuration/indexing-configuration#indexing.temppath).  

* Learn more about RavenDB directory structure [here](../../server/storage/directory-structure).  

---

- **Type**: `string`
- **Default**: `null`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Storage.MaxConcurrentFlushes" id="storage-maxconcurrentflushes" href="#storage-maxconcurrentflushes">

Maximum concurrent flushes.

- **Type**: `int`
- **Default**: `10`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Storage.TimeToSyncAfterFlushInSec" id="storage-timetosyncafterflushinsec" href="#storage-timetosyncafterflushinsec">

Time to sync after flush in seconds

- **Type**: `int`
- **Default**: `30`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Storage.NumberOfConcurrentSyncsPerPhysicalDrive" id="storage-numberofconcurrentsyncsperphysicaldrive" href="#storage-numberofconcurrentsyncsperphysicaldrive">

Number of concurrent syncs per physical drive.

- **Type**: `int`
- **Default**: `3`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Storage.CompressTxAboveSizeInKb" id="storage-compresstxabovesizeinkb" href="#storage-compresstxabovesizeinkb">

Compress transactions above size (value in KB)

- **Type**: `int`
- **Default**: `512`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Storage.ForceUsing32BitsPager" id="storage-forceusing32bitspager" href="#storage-forceusing32bitspager">

Use the 32 bits memory mapped pager even when running on 64 bits.

- **Type**: `bool`
- **Default**: `false`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Storage.MaxScratchBufferSizeInMb" id="storage-maxscratchbuffersizeinmb" href="#storage-maxscratchbuffersizeinmb">

Maximum size of `.buffers` files

- **Type**: `int`
- **Default**: `256` when running on 64 bits, `32` when running on 32 bits or `Storage.ForceUsing32BitsPager` is set to `true`
- **Scope**: Server-wide or per database

</Admonition>


<Admonition type="info" title="Storage.PrefetchBatchSizeInKb" id="storage-prefetchbatchsizeinkb" href="#storage-prefetchbatchsizeinkb">

Size of the batch in kilobytes that will be requested to the OS from disk when prefetching (value in powers of 2). Some OSs may not honor certain values. Experts only.

- **Type**: `int`
- **Default**: `1024`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Storage.PrefetchResetThresholdInGb" id="storage-prefetchresetthresholdingb" href="#storage-prefetchresetthresholdingb">

How many gigabytes of memory should be prefetched before restarting the prefetch tracker table. Experts only.

- **Type**: `int`
- **Default**: `8`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Storage.OnDirectoryInitialize.Exec" id="storage-ondirectoryinitialize-exec" href="#storage-ondirectoryinitialize-exec">

A command or executable to run when creating/opening a directory (storage environment). Experts only.  
RavenDB will execute:  
<TabItem value="something" label="plain">
<CodeBlock language="plain">
{`command [user-arg-1] ... [user-arg-n] <environment-type> <database-name> <data-dir-path> <temp-dir-path> <journal-dir-path>  
`}
</CodeBlock>
</TabItem>

- **Type**: `string`
- **Default**: `null`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Storage.OnDirectoryInitialize.Exec.Arguments" id="storage-ondirectoryinitialize-exec-arguments" href="#storage-ondirectoryinitialize-exec-arguments">

The optional user arguments for the 'Storage.OnDirectoryInitialize.Exec' command or executable. The arguments must be escaped for the command line. Experts only.  

- **Type**: `string`
- **Default**: `null`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Storage.OnDirectoryInitialize.Exec.TimeoutInSec" id="storage-ondirectoryinitialize-exec-timeoutinsec" href="#storage-ondirectoryinitialize-exec-timeoutinsec">

The number of seconds to wait for the OnDirectoryInitialize executable to exit. Default: 30 seconds. Experts only.  

- **Type**: `int`
- **Default**: `30`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Storage.EnablePrefetching" id="storage-enableprefetching" href="#storage-enableprefetching">

Enables memory prefetching mechanism if OS supports it.  

- **Type**: `bool`
- **Default**: `true`
- **Scope**: Server-wide only

</Admonition>
