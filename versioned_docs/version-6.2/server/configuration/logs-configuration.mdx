# Configuration: Logs Options

<Admonition type="info" title="Logs.Path" id="logs-path" href="#logs-path">

The path to the directory where the RavenDB server logs will be stored.  
By default, the logs are placed in the 'Logs' directory in the same folder as the server.

- **Type**: `string`
- **Default**: `Logs`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.Mode" id="logs-mode" href="#logs-mode">

The level of logs that will be written to the log files.  
Available options:

- `None` (logging disabled)
- `Operations` (high level info for operational users)
- `Information` (low level debug info)

---

- **Type**: `string`
- **Default**: `Operations`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.UseUtcTime" id="logs-useutctime" href="#logs-useutctime">

Determine whether logs are timestamped in UTC or with server-local time.

- **Type**: `bool`
- **Default**: `true`
- **Scope**: Server-wide only

<Admonition type="info" title="Info">
Writing logs in UTC is more performant than using server-local time.
</Admonition>

</Admonition>

<Admonition type="info" title="Logs.MaxFileSizeInMb" id="logs-maxfilesizeinmb" href="#logs-maxfilesizeinmb">

The maximum log file size in megabytes.

- **Type**: `int`
- **Default**: `128`
- **Minimum**: `16`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.RetentionTimeInHrs" id="logs-retentiontimeinhrs" href="#logs-retentiontimeinhrs">

The number of hours logs are kept before they are deleted.

- **Type**: `int`
- **Default**: `72`
- **Minimum**: `24`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.RetentionSizeInMb" id="logs-retentionsizeinmb" href="#logs-retentionsizeinmb">

The maximum log size after which older files will be deleted.  
No log files will be deleted if this configuration is not set.

- **Type**: `int`
- **Default**: `null`
- **Minimum**: `256`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.Compress" id="logs-compress" href="#logs-compress">

Determine whether to compress the log files.

- **Type**: `bool`
- **Default**: `false`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.Microsoft.Disable" id="logs-microsoft-disable" href="#logs-microsoft-disable">

Determine whether to disable Microsoft logs.

- **Type**: `bool`
- **Default**: `true`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.Microsoft.ConfigurationPath" id="logs-microsoft-configurationpath" href="#logs-microsoft-configurationpath">

The path to the JSON configuration file for Microsoft logs.

- **Type**: `string`
- **Default**: `settings.logs.microsoft.json`
- **Scope**: Server-wide only

</Admonition>
