<Admonition type="info" title="PerformanceHints.Documents.HugeDocumentsCollectionSize" id="performancehints-documents-hugedocumentscollectionsize" href="#performancehints-documents-hugedocumentscollectionsize">

The maximum size of the huge documents collection.

- **Type**: `int`
- **Default**: `100`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="PerformanceHints.Documents.HugeDocumentSizeInMb" id="performancehints-documents-hugedocumentsizeinmb" href="#performancehints-documents-hugedocumentsizeinmb">

The size of a document after which it will get into the huge documents collection.  
Value is in MB.

- **Type**: `int`
- **Default**: `5`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="PerformanceHints.Indexing.AlertWhenSourceDocumentIncludedInOutput" id="performancehints-indexing-alertwhensourcedocumentincludedinoutput" href="#performancehints-indexing-alertwhensourcedocumentincludedinoutput">

Alert when source document in indexed as field.

- **Type**: `bool`
- **Default**: `true`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="PerformanceHints.Indexing.MaxDepthOfRecursionInLinqSelect" id="performancehints-indexing-maxdepthofrecursioninlinqselect" href="#performancehints-indexing-maxdepthofrecursioninlinqselect">

Maximum depth of recursion in LINQ Select clause.

- **Type**: `int`
- **Default**: `32`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="PerformanceHints.Indexing.MaxIndexOutputsPerDocument" id="performancehints-indexing-maxindexoutputsperdocument" href="#performancehints-indexing-maxindexoutputsperdocument">

The maximum number of index outputs per document after which we will create a performance hint.

- **Type**: `int`
- **Default**: `1024`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="PerformanceHints.Indexing.MaxNumberOfLoadsPerReference" id="performancehints-indexing-maxnumberofloadsperreference" href="#performancehints-indexing-maxnumberofloadsperreference">

The maximum number of `LoadDocument()` / `LoadCompareExchangeValue()` calls per a document/compare-exchange reference value 
after which we will create a performance hint.

- **Type**: `int`
- **Default**: `1024`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="PerformanceHints.MaxNumberOfResults" id="performancehints-maxnumberofresults" href="#performancehints-maxnumberofresults">

The maximum number of query results after which we will create a performance hint.

- **Type**: `int`
- **Default**: `2048`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="PerformanceHints.Memory.MinSwapSizeInMb" id="performancehints-memory-minswapsizeinmb" href="#performancehints-memory-minswapsizeinmb">

* The minimum swap size (Linux only) in Megabytes.  
  If the swap size is below this value, a notification will be triggered.

* The default value is set by the constructor of class `PerformanceHintsConfiguration`:  
  * If the total physical memory is less than 8 GB,  
    the default value is set to 1 GB.
  * If the total physical memory is greater than or equal to 8 GB,  
    the default value is set to the smaller value between half of the total physical memory and 8 GB.

---

- **Type**: `int`
- **Default**: `DefaultValueSetInConstructor`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="PerformanceHints.TooLongRequestThresholdInSec" id="performancehints-toolongrequestthresholdinsec" href="#performancehints-toolongrequestthresholdinsec">

Request latency threshold before the server would issue a performance hint.  
Value is in seconds.

- **Type**: `int`
- **Default**: `30`
- **Scope**: Server-wide or per database

</Admonition>
