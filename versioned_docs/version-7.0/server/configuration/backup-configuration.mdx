<Admonition type="info" title="Backup.TempPath" id="backup-temppath" href="#backup-temppath">

Use this setting to specify a different path to the temporary backup files.  
By default, backup temporary files are written under the Database directory or under [Storage.TempPath](../../server/configuration/storage-configuration) if defined.  
Learn more about RavenDB directory structure [here](../../server/storage/directory-structure).

- **Type**: `string`
- **Default**: `null`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Backup.LocalRootPath" id="backup-localrootpath" href="#backup-localrootpath">

Local backups can only be created under this root path.  

- **Type**: `string`  
- **Default**: `null`  
- **Scope**: Server-wide only  

</Admonition>

<Admonition type="info" title="Backup.AllowedDestinations" id="backup-alloweddestinations" href="#backup-alloweddestinations">

Semicolon separated list of allowed backup destinations. If not specified, all destinations are allowed.   

- **Type**: `string`  
- **Default**: `null`  
- **Scope**: Server-wide only  

Possible values:  

- `None`  
- `Local`  
- `Azure`  
- `AmazonGlacier`  
- `AmazonS3`  
- `FTP`  

</Admonition>

<Admonition type="info" title="Backup.AllowedAwsRegions" id="backup-allowedawsregions" href="#backup-allowedawsregions">

Semicolon separated list of allowed AWS regions. If not specified, all regions are allowed.  

- **Type**: `string`  
- **Default**: `null`  
- **Scope**: Server-wide only  

</Admonition>

<Admonition type="info" title="Backup.MaxNumberOfConcurrentBackups" id="backup-maxnumberofconcurrentbackups" href="#backup-maxnumberofconcurrentbackups">

Maximum number of concurrent backup tasks.  

- **Type**: `int`  
- **Default**: the number of CPU cores assigned to this server, divided by 2.  
  (By default a server with 1, 2, or 3 CPU cores can perform 1 backup at a time. A server with 4 or 5 cores can perform 2 backups at a time, 6 or 7 cores can perform 3, and so on)
- **Scope**: Server-wide only  

</Admonition>

<Admonition type="info" title="Backup.ConcurrentBackupsDelayInSec" id="backup-concurrentbackupsdelayinsec" href="#backup-concurrentbackupsdelayinsec">

Number of seconds to delay the backup after hitting the maximum number of concurrent backups limit (see `MaxNumberOfConcurrentBackups` above).  

- **Type**: `TimeSetting`  
- **TimeUnit**: `TimeUnit.Seconds`  
- **Default**: `30`  
- **Scope**: Server-wide only  

</Admonition>

<Admonition type="info" title="Backup.LowMemoryBackupDelayInMin" id="backup-lowmemorybackupdelayinmin" href="#backup-lowmemorybackupdelayinmin">

Number of minutes to delay the backup if the server enters a low memory state.  

- **Type**: `TimeSetting`  
- **TimeUnit**: `TimeUnit.Minutes`  
- **Default**: `10`  
- **Scope**: Server-wide only  

</Admonition>
