<Admonition type="info" title="Logs.ArchiveAboveSizeInMb" id="logs-archiveabovesizeinmb" href="#logs-archiveabovesizeinmb">

The maximum size (in megabytes) a log file may reach before it is archived and logging is directed to a new file.  
This setting ensures that logs are stored in multiple smaller files rather than a few large ones.

- **Type**: `int`
- **Default**: `128`
- **Min Value**: `16`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.ConfigPath" id="logs-configpath" href="#logs-configpath">

The path to an XML file that overrides all logging configuration parameters.  
Set to `null` to apply the configuration params detailed in this section,  
or provide a path to an XML configuration file whose content overrides these settings.  

- **Type**: `string`
- **Default**: `null`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.EnableArchiveFileCompression" id="logs-enablearchivefilecompression" href="#logs-enablearchivefilecompression">

Determines whether to compress archived log files.

- **Type**: `bool`
- **Default**: `false`
- **Scope**: Server-wide only
- **Alias:** `Logs.Compress`

</Admonition>

<Admonition type="info" title="Logs.MaxArchiveDays" id="logs-maxarchivedays" href="#logs-maxarchivedays">

The maximum number of days to retain an archived log file.  
Set this value to the number of days after which log files will be deleted,  
or set it to `null` to keep log files indefinitely.

- **Type**: `int?`
- **Default**: `3`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.MaxArchiveFiles" id="logs-maxarchivefiles" href="#logs-maxarchivefiles">

The maximum number of archived log files to keep.  
Set to `null` to keep log files indefinitely.

- **Type**: `int?`
- **Default**: `null`
- **Min Value**: `0`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.Microsoft.MinLevel" id="logs-microsoft-minlevel" href="#logs-microsoft-minlevel">

The minimum logging level for Microsoft logs.

- **Type**: `enum LogLevel` (`Trace`, `Debug`, `Info`, `Warn`, `Error`, `Fatal`, `Off`)
- **Default**: `LogLevel.Error`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.MinLevel" id="logs-minlevel" href="#logs-minlevel">

Determines the minimum logging level.  
Log entries will be included starting from the specified MinLevel and higher.  

- **Type**: `enum LogLevel` (`Trace`, `Debug`, `Info`, `Warn`, `Error`, `Fatal`, `Off`)
- **Default**: `LogLevel.Info`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.NuGet.AdditionalPackages" id="logs-nuget-additionalpackages" href="#logs-nuget-additionalpackages">

A dictionary of additional NuGet packages to load during server startup for additional logging targets.  
Each key represents the package name, and the corresponding value specifies the package version.

- **Type**: `Dictionary<string, string>`
- **Default**: `null`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.NuGet.AllowPreReleasePackages" id="logs-nuget-allowprereleasepackages" href="#logs-nuget-allowprereleasepackages">

Determines whether to allow installation of NuGet pre-release packages.

- **Type**: `bool`
- **Default**: `false`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.NuGet.PackagesPath" id="logs-nuget-packagespath" href="#logs-nuget-packagespath">

The path where NuGet packages required by RavenDB are downloaded.

- **Type**: `string`
- **Default**: `Packages/NuGet/Logging`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.NuGet.PackageSourceUrl" id="logs-nuget-packagesourceurl" href="#logs-nuget-packagesourceurl">

The default URL for the NuGet package source.

- **Type**: `string`
- **Default**: `https://api.nuget.org/v3/index.json`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.Path" id="logs-path" href="#logs-path">

The path to the folder where RavenDB server log files are stored.  
By default, it is the `Logs` folder under the server folder.

- **Type**: `string`
- **Default**: `Logs`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.ThrowConfigExceptions" id="logs-throwconfigexceptions" href="#logs-throwconfigexceptions">

Determines whether to throw an exception if NLog detects a logging configuration error.

- **Type**: `bool`
- **Default**: `false`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.Internal.Level" id="logs-internal-level" href="#logs-internal-level">

Determines the logging level for NLog's internal logs.

- **Type**: `enum LogLevel` (`Trace`, `Debug`, `Info`, `Warn`, `Error`, `Fatal`, `Off`)
- **Default**: `LogLevel.Info`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.Internal.LogToStandardError" id="logs-internal-logtostandarderror" href="#logs-internal-logtostandarderror">

Determines whether to write NLog's internal logs to the standard error stream.

- **Type**: `bool`
- **Default**: `false`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.Internal.LogToStandardOutput" id="logs-internal-logtostandardoutput" href="#logs-internal-logtostandardoutput">

Determines whether to write NLog's internal logs to the standard output stream.  
This can be useful when running the server to verify that it operates without issues.

- **Type**: `bool`
- **Default**: `false`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Logs.Internal.Path" id="logs-internal-path" href="#logs-internal-path">

The path to the folder where NLog's internal logs are written.  
This is useful for debugging NLog.

- **Type**: `string`
- **Default**: `null`
- **Scope**: Server-wide only

</Admonition>
