# Configuration: Cluster
---

<Admonition type="note" title="Note">

* **Avoid using different cluster configurations across nodes:**  
  Configuration mismatches can lead to interaction problems between nodes.

* If you must set different configurations for individual nodes,
  we recommend testing the setup in a development environment first to ensure proper interaction between all nodes.

</Admonition>

<Admonition type="info" title="Cluster.CompareExchangeExpiredDeleteFrequencyInSec" id="cluster-compareexchangeexpireddeletefrequencyinsec" href="#cluster-compareexchangeexpireddeletefrequencyinsec">

Time (in seconds) between cleanup of expired compare exchange items.

- **Type**: `int`
- **Default**: `60`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.CompareExchangeTombstonesCleanupIntervalInMin" id="cluster-compareexchangetombstonescleanupintervalinmin" href="#cluster-compareexchangetombstonescleanupintervalinmin">

Time (in minutes) between cleanup of compare exchange tombstones.

- **Type**: `int`
- **Default**: `10`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.ElectionTimeoutInMs" id="cluster-electiontimeoutinms" href="#cluster-electiontimeoutinms">

Timeout (in milliseconds) within which the node expects to receive a heartbeat from the leader.

- **Type**: `int`
- **Default**: `300`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.HardDeleteOnReplacement" id="cluster-harddeleteonreplacement" href="#cluster-harddeleteonreplacement">

Set hard/soft delete for a database that was removed by the observer from the cluster topology in order to maintain the replication factor.

- **Type**: `bool`
- **Default**: `true`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.LogHistoryMaxEntries" id="cluster-loghistorymaxentries" href="#cluster-loghistorymaxentries">

Maximum number of log entries to keep in the history log table.

- **Type**: `int`
- **Default**: `2048`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.MaxChangeVectorDistance" id="cluster-maxchangevectordistance" href="#cluster-maxchangevectordistance">

Exceeding the allowed change vector distance between two nodes will move the lagged node to rehab.

- **Type**: `long`
- **Default**: `65536`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.MaxClusterTransactionCompareExchangeTombstoneCheckIntervalInMin" id="cluster-maxclustertransactioncompareexchangetombstonecheckintervalinmin" href="#cluster-maxclustertransactioncompareexchangetombstonecheckintervalinmin">

The maximum interval (in minutes) between checks for compare exchange tombstones that are performed by the cluster-wide transaction mechanism.

- **Type**: `int`
- **Default**: `5`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.MaxSizeOfSingleRaftCommandInMb" id="cluster-maxsizeofsingleraftcommandinmb" href="#cluster-maxsizeofsingleraftcommandinmb">

EXPERT ONLY:  
The maximum allowed size (in megabytes) for a single raft command.

- **Type**: `int`
- SizeUnit(SizeUnit.Megabytes)
- **Default**: `128`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.MaximalAllowedClusterVersion" id="cluster-maximalallowedclusterversion" href="#cluster-maximalallowedclusterversion">

EXPERT ONLY:  
If exceeded, restrict the cluster to the specified version.

- **Type**: `int?`
- **Default**: `null`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.OnErrorDelayTimeInMs" id="cluster-onerrordelaytimeinms" href="#cluster-onerrordelaytimeinms">

How long the maintenance supervisor waits (in milliseconds) after receiving an exception from a worker before retrying.

- **Type**: `int`
- **Default**: `5000`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.OperationTimeoutInSec" id="cluster-operationtimeoutinsec" href="#cluster-operationtimeoutinsec">

As a cluster node, how long (in seconds) to wait before timing out an operation between two cluster nodes.

- **Type**: `int`
- **Default**: `15`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.ReceiveFromWorkerTimeoutInMs" id="cluster-receivefromworkertimeoutinms" href="#cluster-receivefromworkertimeoutinms">

How long the maintenance supervisor waits (in milliseconds) for a response from a worker before timing out.

- **Type**: `int`
- **Default**: `5000`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.StatsStabilizationTimeInSec" id="cluster-statsstabilizationtimeinsec" href="#cluster-statsstabilizationtimeinsec">

How long to wait (in seconds) for cluster stats to stabilize after a database topology change.

- **Type**: `int`
- **Default**: `5`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.SupervisorSamplePeriodInMs" id="cluster-supervisorsampleperiodinms" href="#cluster-supervisorsampleperiodinms">

How long the maintenance supervisor waits (in milliseconds) between sampling the information received from the nodes.

- **Type**: `int`
- **Default**: `1000`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.TcpReceiveBufferSizeInBytes" id="cluster-tcpreceivebuffersizeinbytes" href="#cluster-tcpreceivebuffersizeinbytes">

The size (in bytes) of the TCP connection receive buffer.

- **Type**: `int`
- **Default**: `32 * 1024`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.TcpSendBufferSizeInBytes" id="cluster-tcpsendbuffersizeinbytes" href="#cluster-tcpsendbuffersizeinbytes">

The size (in bytes) of the TCP connection send buffer.

- **Type**: `int`
- **Default**: `32 * 1024`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.TcpTimeoutInMs" id="cluster-tcptimeoutinms" href="#cluster-tcptimeoutinms">

TCP connection read/write timeout (in milliseconds).

- **Type**: `int`
- **Default**: `15_000`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.TimeBeforeAddingReplicaInSec" id="cluster-timebeforeaddingreplicainsec" href="#cluster-timebeforeaddingreplicainsec">

The time (in seconds) a database instance must be in a good and responsive state before we add a replica to match the replication factor.

- **Type**: `int`
- **Default**: `900`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.TimeBeforeMovingToRehabInSec" id="cluster-timebeforemovingtorehabinsec" href="#cluster-timebeforemovingtorehabinsec">

The grace period (in seconds) we give a node before it is moved to rehab.

- **Type**: `int`
- **Default**: `60`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.TimeBeforeRotatingPreferredNodeInSec" id="cluster-timebeforerotatingpreferrednodeinsec" href="#cluster-timebeforerotatingpreferrednodeinsec">

The grace period (in seconds) we give the preferred node before moving it to the end of the members list.

- **Type**: `int`
- **Default**: `5`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.WorkerSamplePeriodInMs" id="cluster-workersampleperiodinms" href="#cluster-workersampleperiodinms">

The time (in milliseconds) between sampling database information and sending it to the maintenance supervisor.

- **Type**: `int`
- **Default**: `500`
- **Scope**: Server-wide only

</Admonition>

<Admonition type="info" title="Cluster.DisableAtomicDocumentWrites" id="cluster-disableatomicdocumentwrites" href="#cluster-disableatomicdocumentwrites">

EXPERT ONLY:  
Disable automatic atomic writes with cluster write transactions.  
If set to _true_, will only consider explicitly added compare exchange values to validate cluster wide transactions.

- **Type**: `bool`
- **Default**: `false`
- **Scope**: Server-wide or per database

</Admonition>

<Admonition type="info" title="Cluster.MaxClusterTransactionBatchSize" id="cluster-maxclustertransactionbatchsize" href="#cluster-maxclustertransactionbatchsize">

EXPERT ONLY:  
Specifies the maximum size of the cluster transaction batch to be executed on the database at once.

- **Type**: `int`
- **Default**: `256`
- **Scope**: Server-wide or per database

</Admonition>
